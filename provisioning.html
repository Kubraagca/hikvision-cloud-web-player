Windows Kurulumunu Indir

Akis

  1. Windows kurulum dosyasini indir ve calistir.
  2. Yerel agent `127.0.0.1:47831` adresinde ayaga kalkar.
  3. `Yerel Kurulum Ekranini Ac` ile SADP benzeri ekrana gecilir.
  4. Kamera tarama, secme, aktivasyon ve ag ayarlari yerel agent ekranindan yapilir.
Yerel agent ekranı bu alanda acilacak. Agent hazir degilse: 1. Kurulum dosyasini indir. 2. Kurulumu tamamla. 3. `Agent Kontrol Et` butonuna bas. 4. Ardindan `Yerel Kurulum Ekranini Ac` ile devam et.
